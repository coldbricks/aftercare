# Security Policy

**Security Maintainer:** David Lombardo ([@coldbricks](https://github.com/coldbricks) | coldbricks@gmail.com)

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a vulnerability

Please email **David Lombardo** at **coldbricks@gmail.com** with a description of the issue and steps to reproduce.

Do **not** open a public GitHub issue for security-sensitive reports. We will acknowledge receipt and work with you on a fix and disclosure timeline.
